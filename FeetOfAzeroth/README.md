# Feet Of Azeroth

A small travel companion for Azeroth. Display your current coordinates and track the distance you've travelled through the world of Warcraft.

## Development notice

The versions available on GitHub are still under development. They may contain bugs, and some features may not yet be fully functional. Stable versions are available in the "releases" folder.

Get the stable release on CurseForge: as soon as possible !

* Display of the player's current coordinates
* Dispaly of the player's current speed
* Distance travelled during the current session
* Total distance travelled since the addon was installed
* Switch between meters and yards
* Time spent AFK
* Time spent as a ghost
* Keep track of the speed record, total distance travelled, time spent AFK and time as a ghost
* Achievements to unlock based on the distance travelled
* Addon statistics

Several display modes are available

### Mode 1
* Distance travelled during the current session 
* Total distance travelled since the addon was installed
* Coordinates

### Mode 2
* Total distance travelled since the addon was installed
* Player's current speed
* Coordinates

### Mode 3
* Distance travelled during the current session 
* Player's current speed
* Coordinates

### Mode 4
* Display a joke
* Display current time
* Coordinates

### Mode 5
* Time spent as AFK
* Time spent as a ghost
* Coordinates
